# 🛡️ Zero-Leak: AI-Powered Expense & Compliance Engine
**Secure Revenue Protection for MSMEs** *Official Submission for Odoo x VIT Pune Hackathon '26 (Virtual Screening Phase)*

---

## 📖 Overview
**Zero-Leak** is a specialized financial compliance terminal designed to eliminate internal revenue "leaks" in MSMEs. By combining a **Zero-Trust Authentication** gateway with a high-performance **MySQL backend**, the engine ensures that every corporate expense and organization detail is audited, encrypted, and compliant.

## 💎 Key Highlights
- **Deep-Blur UI:** A high-end, banking-grade interface for a professional user experience.
- **Secure Onboarding:** Automated organization registration with real-time currency detection via RestCountries API.
- **Identity Assurance:** Session management secured by **JWT (JSON Web Tokens)** and **AES-256** password hashing.
- **Monorepo Architecture:** Clean separation of concerns between the React frontend and Node.js backend.
